# 演示シナリオ

base は `main`。対象の head をローカルへ取得し、作業ツリーを base SHA に合わせてから SCM レビューする。
LLM 応答は固定の合成データを使用する。行と根拠の検証、Git と SQLite の処理は実際に動作する。

| head | 主な指摘 |
|---|---|
| `demo/sql-lookup` | メール照会の SQL 注入 |
| `demo/template-preview` | テンプレートのパストラバーサル |
| `demo/missing-order` | 404 を返す注文照会契約の違反 |
| `demo/sql-lookup-fixed` | SQL 注入修正後の対照 |

SQL 注入の PR で、変更行・レビュー結果・投稿計画を順に示す。
修正済みブランチは、同じ PR の head を進める場合の試料として使う。
